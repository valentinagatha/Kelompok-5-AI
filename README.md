# Kelompok-5-AI
Masalah dalam Cloud System: /n
memerlukan internet yg stabil untuk bisa mengakses data-data di cloud sehingga tidak accessible kapan saja dan di mana saja
seringkali lupa mematikan setting sinkronisasi cloud ketika ingin menghapus data dari satu device sehingga di cloud ikut terhapus
seringkali upload file yang sama berkali-kali sehingga cloud storage penuh 
auto backup membuat berbagai jenis foto tercampur (misal: foto pemandangan dengan foto berkas formal) sehingga tidak lgsg tersaring
format file yang di-upload di satu device tidak mendukung di device lain
seringkali lupa mematikan fitur langganan ketika sudah tidak butuh storage cloud lagi
sharing cloud membuat file-file kita masuk ke device orang lain
bingung bagaimana cara transfer data-data di cloud ketika beli hp dengan merek yang berbeda
penyimpanan device yang masih penuh padahal sudah aktivasi cloud
bingung cara membedakan berbagai macam cloud (google drive, google photo, dll)
sering kesulitan menemukan file tertentu karena terlalu banyak dokumen yang tersimpan tanpa pengelompokan yang jelas
terkadang tidak mengetahui bahwa file yang dibagikan kepada orang lain masih bisa diakses meskipun sudah tidak diperlukan
kesulitan mengakses akun cloud ketika lupa kata sandi atau kehilangan akses ke nomor telepon untuk verifikasi
sering salah memberikan izin akses sehingga orang lain bisa mengedit file yang seharusnya hanya boleh dilihat
proses upload file berukuran besar membutuhkan waktu lama sehingga menghambat pekerjaan
kesulitan mengetahui siapa yang terakhir mengubah dokumen ketika file digunakan bersama oleh beberapa orang
file yang sudah dihapus masih bisa ditemukan di folder sampah sehingga bingung apakah data tersebut benar-benar sudah terhapus
merasa khawatir menyimpan dokumen penting di cloud karena tidak mengetahui bagaimana keamanan data tersebut
kesulitan memindahkan banyak file dari satu layanan cloud ke layanan cloud lainnya
sering lupa mengubah izin akses dokumen ketika sudah tidak bekerja sama dengan orang yang sebelumnya diberikan akses
kesulitan membuka file ketika layanan cloud sedang mengalami gangguan atau tidak bisa digunakan sementara waktu
tidak mengetahui file mana yang paling banyak menggunakan kapasitas penyimpanan cloud
kesulitan memisahkan dokumen pribadi dan dokumen pekerjaan ketika keduanya disimpan dalam satu akun cloud
membutuhkan waktu lama untuk memulihkan data ketika file penting tidak sengaja terhapus
perubahan dokumen yang dilakukan di satu perangkat terkadang tidak langsung muncul di perangkat lainnya
