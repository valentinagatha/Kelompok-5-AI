# Kelompok-5-AI

## Masalah dalam Cloud System:
1. memerlukan internet yg stabil untuk bisa mengakses data-data di cloud sehingga tidak accessible kapan saja dan di mana saja
2. seringkali lupa mematikan setting sinkronisasi cloud ketika ingin menghapus data dari satu device sehingga di cloud ikut terhapus
3. seringkali upload file yang sama berkali-kali sehingga cloud storage penuh 
4. auto backup membuat berbagai jenis foto tercampur (misal: foto pemandangan dengan foto berkas formal) sehingga tidak lgsg tersaring
5. format file yang di-upload di satu device tidak mendukung di device lain
6. seringkali lupa mematikan fitur langganan ketika sudah tidak butuh storage cloud lagi.
7. sharing cloud membuat file-file kita masuk ke device orang lain
8. bingung bagaimana cara transfer data-data di cloud ketika beli hp dengan merek yang berbeda
9. penyimpanan device yang masih penuh padahal sudah aktivasi cloud
10. bingung cara membedakan berbagai macam cloud (google drive, google photo, dll)
11. sering kesulitan menemukan file tertentu karena terlalu banyak dokumen yang tersimpan tanpa pengelompokan yang jelas
12. terkadang tidak mengetahui bahwa file yang dibagikan kepada orang lain masih bisa diakses meskipun sudah tidak diperlukan
13. kesulitan mengakses akun cloud ketika lupa kata sandi atau kehilangan akses ke nomor telepon untuk verifikasi
14. sering salah memberikan izin akses sehingga orang lain bisa mengedit file yang seharusnya hanya boleh dilihat
15. proses upload file berukuran besar membutuhkan waktu lama sehingga menghambat pekerjaan
16. kesulitan mengetahui siapa yang terakhir mengubah dokumen ketika file digunakan bersama oleh beberapa orang
17. file yang sudah dihapus masih bisa ditemukan di folder sampah sehingga bingung apakah data tersebut benar-benar sudah terhapus
18. merasa khawatir menyimpan dokumen penting di cloud karena tidak mengetahui bagaimana keamanan data tersebut
19. kesulitan memindahkan banyak file dari satu layanan cloud ke layanan cloud lainnya
20. sering lupa mengubah izin akses dokumen ketika sudah tidak bekerja sama dengan orang yang sebelumnya diberikan akses
21. kesulitan membuka file ketika layanan cloud sedang mengalami gangguan atau tidak bisa digunakan sementara waktu
22. tidak mengetahui file mana yang paling banyak menggunakan kapasitas penyimpanan cloud
23. kesulitan memisahkan dokumen pribadi dan dokumen pekerjaan ketika keduanya disimpan dalam satu akun cloud
24. membutuhkan waktu lama untuk memulihkan data ketika file penting tidak sengaja terhapus
25. perubahan dokumen yang dilakukan di satu perangkat terkadang tidak langsung muncul di perangkat lainnya
26. kesulitan mengelola banyak akun cloud karena setiap layanan memiliki pengaturan yang berbeda
27. tidak mengetahui apakah file penting yang disimpan di cloud sudah memiliki salinan cadangan
28. sering kesulitan membuka tautan file yang dibagikan orang lain karena harus menggunakan akun tertentu
29. kesulitan mengatur masa berlaku akses file yang dibagikan sehingga dokumen masih bisa dibuka dalam waktu yang tidak diinginkan
30. biaya penggunaan cloud storage semakin mahal ketika membutuhkan kapasitas penyimpanan yang lebih besar
31. banyak website punya ketergantungan ke provider seperti AWS, jadi ketika provider down/bermasalah, semua ikut terdampak
32. banyak resource yang tidak dipakai (awalnya untuk testing) lupa dimatikan jadi tetap makan biaya tiap bulan
33. provider untuk server, storage, database, dll kebanyakan berasal dari US dan memakai dollar sehingga kurang cocok untuk UMKM jika ingin digunakan
34. provider sering menjanjikan uptime 99% tapi kenyataannya sistem masih bisa down sekitar 8,7 jam per tahun, ketika provider melanggar kompensasinya hanya sekedar kredit
35. banyak karyawan yang menyimpan data perusahaan/pekerjaan di cloudnya sendiri (ada potensi data tersebar), dan tim IT tidak tahu
36. pada bisnis kecil, akun utama cloud biasanya hanya dipegang satu orang sehingga perusahaan punya ketergantungan ke orang tersebut
37. risiko penggunaan AI dalam cloud untuk kegiatan pendidikan
38. ketergantungan terhadap layanan cloud berbayar
39. seorang insinyur menggunakan claude untuk membuat versi gratis photoshop, word, figma, dan autocad dalam dua minggu, tetapi adobe berpotensi memperoleh keuntungan dari perkembangan AI
40. remaja kanada yang rutin menggunakan ai untuk tugas sekolah tertinggal dua tahun dibandingkan yang tidak menggunakannya, sementara penelitian lain menunjukkan ai dapat meningkatkan pembelajaran hingga dua kali lipat
41. OpenAI mengklaim berhasil menyelesaikan masalah matematika navier-stokes senilai satu juta dolar, tetapi muncul tuduhan bahwa penelitian tersebut menyalin karya pihak lain
42. kebocoran kode PHP memicu peringatan global dan membuat pemerintah serta perusahaan besar menonaktifkan sejumlah situs web
43. pusat data AI mengkonsumsi listrik dalam jumlah besar sehingga meningkatkan kebutuhan energi dan biaya operasional
44. saham teknologi dan obligasi AI mengalami penurunan tajam yang memicu kekhawatiran terhadap investasi AI
45. gangguan google cloud menyebabkan puluhan situs web dan aplikasi mengalami masalah layanan
46. keamanan data dan hak kekayaan intelektual di cloud
47. kerentanan keamanan pada sistem cloud akibat kebocoran kode
48. konsumsi energi cloud computing yang semakin tinggi
49. ketidakstabilan investasi dan biaya layanan cloud
50. gangguan layanan cloud yang berdampak pada berbagai platform
