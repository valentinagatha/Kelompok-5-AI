Panduan Mudah

Cara Cepat Ekspor Kontak & Kalender

Sebelum mengemas dengan Moviu, dapatkan berkas kontak dan kalender dari HP lamamu dalam hitungan detik:

🤖 Dari Android

Ekspor Kontak (.vcf) & Kalender

  1. Buka aplikasi Kontak (Google Contacts).
  2. Ketuk tab Kelola Kontak atau menu pengaturan di pojok atas.
  3. Pilih Ekspor ke File .vcf dan simpan ke folder Unduhan/Downloads.
  4. Untuk Kalender: Buka calendar.google.com di browser, pilih Pengaturan ➔ Ekspor Kalender (.ics).
🍎 Dari iPhone (iOS)

Ekspor Kontak (.vcf) & Kalender

  1. Buka aplikasi Kontak di iPhone.
  2. Pilih Daftar (Lists) di pojok kiri atas.
  3. Tekan lama pada daftar Semua Kontak, lalu pilih Ekspor.
  4. Pilih opsi Simpan ke File untuk mendapatkan berkas .vcf.
  5. Untuk Kalender: Buka icloud.com/calendar, jadikan kalender publik sesaat untuk menyalin tautan .ics.
💡 Tips WhatsApp & Media

Persiapan Tambahan

  1. WhatsApp: Buka WhatsApp ➔ Pengaturan ➔ Chat ➔ Cadangan Chat (lakukan cadangan terakhir).
  2. Foto & Video: Pilih langsung dari galeri atau aplikasi File saat menyiapkan paket Moviu.
  3. M-Banking: Pastikan pulsa dan SMS OTP aktif pada nomor HP sebelum memindahkan kartu SIM.

Tanya Jawab

Pertanyaan yang Sering Diajukan

Semua yang perlu kamu ketahui tentang pemindahan data menggunakan Moviu.

Apakah data saya aman dan tidak diunggah ke internet?

Ya, 100% aman dan privat. Moviu dirancang dengan arsitektur local-first. Seluruh proses pembacaan file dan pengemasan ke dalam format ZIP berlangsung di dalam browser perangkatmu (menggunakan Web APIs dan Blob di memori perangkat). Tidak ada satu pun byte foto, kontak, atau dokumen yang dikirimkan ke server eksternal.

Bagaimana cara memindahkan paket ZIP ini ke HP baru?

Setelah mengunduh file Moviu-paket-*.zip, kamu bisa mentransfernya ke HP baru menggunakan cara yang paling kamu sukai:

• Android ke iPhone: Kirim via kabel USB ke komputer, gunakan Google Drive/iCloud web, atau transfer lokal via browser.
• Android ke Android: Gunakan fitur Quick Share (Nearby Share) atau kabel OTG.
• iPhone ke iPhone: Gunakan AirDrop langsung ke HP baru.

Bagaimana cara mengimpor kontak dan kalender dari paket ZIP?

Ekstrak paket ZIP di HP barumu menggunakan aplikasi File. Di dalam folder Moviu/Kontak, ketuk file .vcf maka HP kamu (baik Android maupun iPhone) akan otomatis memunculkan opsi "Tambahkan semua kontak ke Buku Telepon". Hal yang sama berlaku untuk berkas .ics di folder Kalender.

Bagaimana dengan riwayat chat WhatsApp?

WhatsApp memiliki sistem enkripsi sendiri. Cara terbaik untuk memindahkan WhatsApp saat ini adalah menggunakan fitur resmi "Transfer Chat" di menu Pengaturan WhatsApp pada HP lama, lalu pindai kode QR di WhatsApp HP baru sebelum melepas kartu SIM.

Apakah Moviu bisa digunakan saat tidak ada koneksi internet?

Bisa! Setelah halaman Moviu pertama kali termuat, semua mesin pengemasan berkas ZIP dapat berjalan sepenuhnya offline tanpa koneksi internet sama sekali.
