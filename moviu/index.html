TANYA JAWAB UMUM

Pertanyaan yang Sering Diajukan

Semua yang perlu kamu ketahui tentang keamanan data dan cara pemindahan dengan Moviu.

Apakah data saya aman dan tidak diunggah ke internet?

Ya, 100% aman dan privat. Moviu dirancang dengan arsitektur local-first yang patuh pada UU Pelindungan Data Pribadi No. 27 Tahun 2022. Seluruh proses pembacaan file dan pengemasan ke dalam format ZIP berlangsung di memori browser perangkatmu. Tidak ada satu pun byte foto, kontak, atau dokumen yang dikirimkan ke server eksternal.

Bagaimana cara memindahkan paket ZIP ini ke HP baru?

Setelah mengunduh file Moviu-paket-*.zip, kamu bisa mentransfernya ke HP baru menggunakan cara yang paling kamu sukai:

• Android ke iPhone: Kirim via kabel USB ke komputer, gunakan Google Drive/iCloud web, atau transfer lokal via browser.
• Android ke Android: Gunakan fitur Quick Share (Nearby Share) atau kabel OTG.
• iPhone ke Android / iPhone: Gunakan kabel data Type-C atau flashdisk OTG.

Bagaimana cara mengimpor kontak dan kalender dari paket ZIP?

Ekstrak paket ZIP di HP barumu menggunakan aplikasi File. Di dalam folder Moviu/Kontak, ketuk file .vcf maka HP kamu (baik Android maupun iPhone) akan otomatis memunculkan opsi "Tambahkan semua kontak ke Buku Telepon". Hal yang sama berlaku untuk berkas .ics di folder Kalender.

Bagaimana dengan riwayat chat WhatsApp?

WhatsApp memiliki enkripsi end-to-end khusus. Cara terbaik untuk memindahkan WhatsApp saat ini adalah menggunakan fitur resmi "Transfer Chat" di menu Pengaturan WhatsApp pada HP lama, lalu pindai kode QR di WhatsApp HP baru sebelum melepas kartu SIM. Panduan detailnya dapat dilihat di halaman Panduan Ekspor.
